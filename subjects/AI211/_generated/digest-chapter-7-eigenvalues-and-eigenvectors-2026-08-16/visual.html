1 · Concept map — how the whole chapter hangs together

Left lane: any square matrix. Right lane: the special case A = Aᵀ. Everything grows from one equation.

Read the two lanes as the same procedure at two strengths. The left lane must stop and count; the right lane never does, because Theorem 7.7 has already done the counting for you.

2 · Mechanism — what A x = λ x actually says

p.3 → slide 5. An eigenvector is a direction the matrix cannot rotate off its own line.

Why “nonzero” is load-bearing. A·0 = λ·0 holds for every λ. Permit x = 0 and every scalar becomes an eigenvalue of every matrix — the definition would say nothing. Note the mirror-image fact: λ = 0 is perfectly legal (it means A is singular). The scalar may vanish; the vector may not.

3 · Mechanism — reading eigenvalues straight off the geometry

Example 3, pp.6–7 → slides 11–13. A = [[−1,0],[0,1]] reflects vectors in the y-axis.

Transferable rule for any reflection. The mirror line is fixed (λ = +1); the axis perpendicular to the mirror is flipped (λ = −1). Recognise the transformation before reaching for algebra.

5 · Mechanism — the multiplicity gap (the chapter’s pivotal contrast)

Left: Example 5, pp.9–10 → slides 17–19. Right: Example 8, p.13 → slides 25–26. Same n, same “repeated eigenvalue”, opposite verdicts.

The #1 exam trap lives here. Both matrices are 3 × 3 with a repeated eigenvalue, and they land on opposite verdicts. So “repeated eigenvalue” is never an answer — it is an instruction: go and count the linearly independent eigenvectors. Theorem 7.6 (n distinct ⇒ diagonalizable) is sufficient, not necessary; only Theorem 7.5 settles the question in both directions.

6 · Mechanism — how P and D are wired together

Steps for diagonalizing, pp.18–19 → slides 36–37. Worked on Example 4, pp.19–20 → slides 38–40.

P must be invertible, and a square matrix is invertible exactly when its columns are linearly independent. That single equivalence is what turns “is A diagonalizable?” into “can I find n independent eigenvectors?” — i.e. into Theorem 7.5.

8 · Mechanism — the mirrored pair: pathologies vs guarantees

Non-symmetric failures, pp.26–27 → slides 52–53. Theorem 7.7, p.27 → slide 54. Each row is an exact negation of the other.

Learn the two columns as a mirrored pair, never as two separate lists. If you can state either side, you can reconstruct the other by negating it row by row.
