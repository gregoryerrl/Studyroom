# How I learn best

> Studyroom appends this file to every Claude prompt (see design doc §7.0).
> Edit it freely, in your own words — it tunes how ALL answers and generated
> study materials are written. This is a starter; make it yours.

- I retain best with **visual explanations**: diagrams, concept maps, spatial layouts that show how ideas relate.
- I also want **real technical depth**: precise definitions and fully worked, step-by-step examples — no hand-waving.
- Structure beats prose. Walls of text lose me.
- When testing me, prefer exam-style questions over trivia, and make me work for the answer before revealing it.
- Materials may be in English or Filipino; I want outputs in English.
